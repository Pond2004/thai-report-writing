# โครงสร้างรายงานแต่ละประเภท

ใช้เป็นค่าเริ่มต้นเมื่อผู้ใช้ไม่มี template ของตัวเอง ถ้ามี ให้ยึด template นั้น ตัดหัวข้อที่ไม่เกี่ยวออกได้ แต่อย่าเติมหัวข้อที่ไม่มีเนื้อหารองรับ

## A. รายงานวิชาการ / โครงงาน / รายงานฝึกงานฉบับสมบูรณ์

**ส่วนหน้า**
- ปกนอก / ปกใน (ชื่อรายงาน ผู้จัดทำ รหัสนักศึกษา รายวิชา/หลักสูตร สถาบัน ภาคการศึกษา ปีการศึกษา)
- บทคัดย่อ (ไทย และอังกฤษถ้าสถาบันกำหนด) — ย่อหน้าเดียวถึงสองย่อหน้า ครอบคลุม ปัญหา → วิธีการ → ผลที่วัดได้ → ข้อสรุป ไม่ใส่การอ้างอิง ไม่ใส่ตาราง
- กิตติกรรมประกาศ — สั้น ระบุชื่อและตำแหน่งจริงของผู้ที่ขอบคุณ ห้ามแต่งชื่อ
- สารบัญ / สารบัญตาราง / สารบัญรูป
- คำอธิบายสัญลักษณ์และคำย่อ (ถ้ามีมาก)

**เนื้อหา**
1. **บทที่ 1 บทนำ** — ที่มาและความสำคัญของปัญหา, วัตถุประสงค์ (เป็นข้อ วัดผลได้), ขอบเขตของการศึกษา, ประโยชน์ที่คาดว่าจะได้รับ, นิยามศัพท์เฉพาะ
2. **บทที่ 2 ทฤษฎีและงานที่เกี่ยวข้อง** — เฉพาะทฤษฎีที่ใช้จริงในบทที่ 3–4 ทุกสมการต้องอธิบายตัวแปรและหน่วย
3. **บทที่ 3 วิธีการดำเนินงาน** — ขั้นตอน อุปกรณ์ ข้อมูลที่ใช้ (แหล่ง ช่วงเวลา จำนวน) วิธีวิเคราะห์ สมมติฐาน
4. **บทที่ 4 ผลการดำเนินงานและการวิเคราะห์** — นำเสนอผลด้วยตาราง/กราฟ แล้วอธิบายว่าผลบอกอะไร เทียบกับวัตถุประสงค์
5. **บทที่ 5 สรุปผลและข้อเสนอแนะ** — สรุปตอบวัตถุประสงค์ทีละข้อ, ปัญหาและอุปสรรค, ข้อเสนอแนะ (ทำได้จริง ระบุผู้รับผิดชอบหรือเงื่อนไข)

**ส่วนท้าย** — บรรณานุกรม, ภาคผนวก (ข้อมูลดิบ การคำนวณละเอียด แบบฟอร์ม), ประวัติผู้จัดทำ

### รายงานฝึกงาน/สหกิจศึกษา (เพิ่มเติม)

มักแทรกบทนี้หลังบทนำ:
- **ข้อมูลสถานประกอบการ** — ชื่อ ที่ตั้ง ลักษณะธุรกิจ ผลิตภัณฑ์ โครงสร้างองค์กร หน่วยงานที่ฝึก ชื่อและตำแหน่งพนักงานที่ปรึกษา
- **งานที่ได้รับมอบหมาย** — ตารางรายสัปดาห์หรือรายโครงการ
- **สิ่งที่ได้เรียนรู้** — ความรู้ทางเทคนิค ทักษะ และการนำไปใช้ เขียนเป็นตัวอย่างเหตุการณ์จริง ไม่เขียนลอย ๆ เช่น `ได้เรียนรู้การทำงานเป็นทีม`

ข้อมูลที่เป็นความลับของบริษัท (ตัวเลขการผลิต ต้นทุน สูตร) ให้ถามผู้ใช้ก่อนว่าเปิดเผยได้แค่ไหน

## B. รายงานเทคนิค / วิศวกรรม / project ในโรงงาน

ผู้อ่านคือวิศวกรหรือผู้จัดการที่ต้องตัดสินใจ วางข้อสรุปไว้หน้าแรก

1. **Executive summary** (ครึ่งหน้า) — ปัญหา, สิ่งที่ทำ, ผลลัพธ์เป็นตัวเลข, ข้อเสนอและสิ่งที่ต้องอนุมัติ
2. **ที่มาและปัญหา** — สภาพปัจจุบัน (baseline) พร้อมตัวเลข และผลกระทบ (พลังงาน ความปลอดภัย คุณภาพ ต้นทุน)
3. **วัตถุประสงค์และเกณฑ์ความสำเร็จ** — เป้าหมายที่วัดได้
4. **ข้อมูลและวิธีการ** — แหล่งข้อมูล (tag, ระบบ, ช่วงเวลา), การกรองข้อมูล, สมมติฐาน, วิธีคำนวณ/โมเดล
5. **ผลการวิเคราะห์** — ผลหลักก่อน รายละเอียดตามมา ระบุความไม่แน่นอนหรือข้อจำกัดของข้อมูล
6. **ทางเลือกและการเปรียบเทียบ** (ถ้ามี) — ตารางเทียบ ค่าใช้จ่าย ผลที่ได้ ความเสี่ยง ระยะเวลา
7. **ข้อเสนอแนะและแผนดำเนินการ** — ทำอะไร ใครทำ เมื่อไร ต้องใช้อะไร
8. **ภาคผนวก** — การคำนวณ datasheet P&ID ข้อมูลดิบ

รายงานสั้นแบบ one-page (A3 / A4 summary) ใช้ลำดับเดียวกันแต่ตัดเหลือ ปัญหา → สาเหตุ → การแก้ไข → ผล → ขั้นต่อไป

### Root cause / incident report

เหตุการณ์ (อะไร ที่ไหน เมื่อไร) → ผลกระทบ → การตอบสนองทันที → การวิเคราะห์สาเหตุ (5 Why / fishbone) → สาเหตุราก → มาตรการแก้ไขและป้องกัน (ผู้รับผิดชอบ กำหนดเสร็จ) → การติดตามผล

## C. รายงานทางการ / องค์กร

### บันทึกข้อความ (ภายในหน่วยงาน)

ส่วนราชการ/หน่วยงาน, ที่, วันที่, เรื่อง, เรียน, แล้วเนื้อความ 3 ย่อหน้า:
1. **ส่วนเหตุ** — อ้างถึงเรื่องเดิมหรือที่มา (`ตามที่...`, `ด้วย...`)
2. **ส่วนความประสงค์/ข้อเท็จจริง** — รายละเอียด (`ในการนี้...`, `บัดนี้...`)
3. **ส่วนสรุป** — สิ่งที่ขอ (`จึงเรียนมาเพื่อโปรดพิจารณา` / `...เพื่อโปรดทราบ` / `...เพื่อโปรดอนุมัติ`)

ลงชื่อ (ชื่อเต็มในวงเล็บ) และตำแหน่ง

### รายงานการประชุม

ชื่อการประชุม, ครั้งที่, วัน เวลา สถานที่, ผู้มาประชุม / ผู้ไม่มาประชุม / ผู้เข้าร่วม, เริ่มประชุมเวลา
- ระเบียบวาระที่ 1 เรื่องที่ประธานแจ้งให้ที่ประชุมทราบ
- ระเบียบวาระที่ 2 รับรองรายงานการประชุมครั้งที่แล้ว
- ระเบียบวาระที่ 3 เรื่องสืบเนื่อง
- ระเบียบวาระที่ 4 เรื่องเพื่อพิจารณา
- ระเบียบวาระที่ 5 เรื่องอื่น ๆ

แต่ละวาระมี สาระสำคัญ → **มติที่ประชุม** → (ผู้รับผิดชอบ / กำหนดเสร็จ) ปิดด้วย เลิกประชุมเวลา, ผู้จดรายงาน, ผู้ตรวจรายงาน

### รายงานเสนอผู้บริหาร

เรื่อง → สรุปสั้น (2–3 บรรทัด) → ข้อเท็จจริง → ข้อพิจารณา/ทางเลือก → ข้อเสนอ → สิ่งที่ขอให้ผู้บริหารตัดสินใจ

## D. รายงานทั่วไป / ภายในทีม

### สรุปงานประจำสัปดาห์/เดือน

- งานที่เสร็จ (พร้อมผลหรือตัวเลข)
- งานที่กำลังทำ (สถานะ %, ปัญหาที่ติด)
- แผนช่วงถัดไป
- สิ่งที่ต้องการความช่วยเหลือ/การตัดสินใจ

### รายงานกิจกรรม / สรุปการอบรม / ดูงาน

ชื่อกิจกรรม วันที่ สถานที่ ผู้เข้าร่วม → วัตถุประสงค์ → สรุปเนื้อหาสำคัญ (3–5 ประเด็น) → สิ่งที่นำไปใช้ได้กับงานของเรา → ข้อเสนอแนะ → ภาพประกอบ (ถ้ามี)

### รายงานค้นคว้าทั่วไป (ส่งครู/อาจารย์ระดับพื้นฐาน)

ปก → คำนำ → สารบัญ → เนื้อหา (แบ่งหัวข้อตามประเด็น) → บทสรุป → บรรณานุกรม

**คำนำ** บอกว่ารายงานนี้ทำในรายวิชาอะไร มีเนื้อหาอะไร ใครควรอ่าน และขอบคุณผู้ที่เกี่ยวข้อง ปิดด้วยชื่อผู้จัดทำและวันที่ ไม่ต้องใช้สำนวนอย่าง `หากรายงานฉบับนี้มีข้อผิดพลาดประการใด ผู้จัดทำขออภัยมา ณ ที่นี้` เว้นแต่ผู้ใช้ต้องการตามธรรมเนียมของสถาบัน
