# ธรรมเนียมการเขียนรายงานภาษาไทย

ค่าเริ่มต้นตามแนวปฏิบัติที่มหาวิทยาลัยและองค์กรไทยส่วนใหญ่ใช้ ถ้าสถาบันของผู้ใช้กำหนดต่างไป ให้ยึดของสถาบัน

## การเว้นวรรค

- ไม่เว้นวรรคระหว่างคำไทยภายในประโยค
- เว้นวรรค 1 ช่องระหว่างประโยค/วลีที่จบความ (แทนจุด)
- เว้นวรรคหน้าและหลังคำภาษาอังกฤษหรือตัวเลขที่อยู่กลางข้อความไทย เช่น `ค่า SPC ของ CLOX1 ลดลง 5.2%`
- ระหว่างตัวเลขกับหน่วยเว้น 1 ช่อง (`120 Nm³/h`, `7.5 bar`) ยกเว้น `%` และ `°C` ที่ติดตัวเลขได้ ใช้แบบเดียวกันทั้งเล่ม
- ไม้ยมก (ๆ) และ ฯลฯ เว้นวรรคหน้าและหลัง: `ต่าง ๆ`, `ปั๊ม วาล์ว ฯลฯ`
- ใช้ `เป็นต้น` หรือ `ฯลฯ` อย่างใดอย่างหนึ่ง ไม่ใช้คู่กัน
- ก่อนและหลังวงเล็บ เว้นวรรคด้านนอก ไม่เว้นด้านใน: `ระบบควบคุม (control system) ทำงาน...`

## ตัวเลขและหน่วย

- ใช้เลขอารบิกเป็นค่าเริ่มต้น ใช้เลขไทยเมื่อสถาบันหรือหนังสือราชการกำหนด และใช้แบบเดียวตลอดทั้งเล่ม
- ใช้หน่วย SI และสัญลักษณ์มาตรฐาน ระบุหน่วยในหัวคอลัมน์ตาราง เช่น `กำลังไฟฟ้า (kW)`
- ทศนิยมจำนวนตำแหน่งเท่ากันในตารางเดียวกัน
- ปีให้ระบุ พ.ศ. หรือ ค.ศ. ให้ชัด รายงานวิชาการไทยส่วนใหญ่ใช้ พ.ศ. ในเนื้อความ และใช้ปีตามต้นฉบับในการอ้างอิง

## ตารางและรูป

- **ตาราง**: คำบรรยาย*เหนือ*ตาราง `ตารางที่ 4.1 ค่าการใช้พลังงานจำเพาะก่อนและหลังปรับปรุง`
- **รูป**: คำบรรยาย*ใต้*รูป `รูปที่ 3.2 แผนผังระบบอัดอากาศ`
- ตั้งเลขตามบท (4.1, 4.2) ในรายงานที่แบ่งบท ตั้งเลขต่อเนื่อง (1, 2, 3) ในรายงานสั้น
- ทุกตาราง/รูปต้องถูกอ้างถึงในเนื้อความก่อนปรากฏ (`ดังตารางที่ 4.1`) และต้องมีประโยคอธิบายว่าตาราง/รูปนั้นบอกอะไร ไม่ปล่อยตารางลอยโดยไม่มีคำอธิบาย
- รูปที่นำมาจากแหล่งอื่นต้องระบุที่มาใต้คำบรรยาย `ที่มา: ...`

## สมการ

- ใส่เลขสมการท้ายบรรทัด (3.1) และอ้างในเนื้อความว่า `จากสมการที่ (3.1)`
- อธิบายตัวแปรทุกตัวพร้อมหน่วยทันทีหลังสมการ เริ่มด้วย `โดยที่`

## การอ้างอิง

- ค่าเริ่มต้นใช้ **APA 7** ปรับสำหรับภาษาไทย (สายวิศวกรรมบางแห่งใช้ IEEE ให้ถามหรือตามที่สถาบันกำหนด)
- ในเนื้อความ: `(สมชาย ใจดี, 2565)` สำหรับผู้แต่งไทยใช้ชื่อ-นามสกุล, `(Smith, 2020)` สำหรับผู้แต่งต่างชาติใช้นามสกุล
- บรรณานุกรม: เรียงรายการภาษาไทยก่อน ตามด้วยภาษาอังกฤษ เรียงตามตัวอักษร
- **ห้ามแต่งแหล่งอ้างอิง** ถ้าไม่มีแหล่งจริงที่ตรวจสอบได้ ให้ใส่ `[ต้องเติม: แหล่งอ้างอิง]`
- คู่มือ datasheet มาตรฐาน (เช่น ISO, ISA) และเอกสารภายในบริษัท อ้างได้ แต่ระบุเลขเอกสารและฉบับ

## ศัพท์เฉพาะและคำย่อ

- คำย่อครั้งแรกให้เขียนเต็ม: `ประสิทธิผลโดยรวมของเครื่องจักร (Overall Equipment Effectiveness, OEE)` จากนั้นใช้ `OEE`
- เลือกคำเดียวแล้วใช้ตลอด ห้ามสลับ เช่น `เครื่องอัดอากาศ` / `compressor` / `ปั๊มลม` ในรายงานเดียวกัน
- ชื่อ tag, ชื่ออุปกรณ์, ชื่อซอฟต์แวร์ เขียนตามต้นฉบับ (`FV-X1983-02`, `Seeq`, `Power BI`)

## ระดับภาษาในรายงานทางการ

| เลี่ยง (ภาษาพูด/AI) | ใช้ |
|---|---|
| เยอะ, เยอะมาก | มาก, จำนวนมาก (หรือระบุตัวเลข) |
| ได้ผลดีมาก ๆ | ระบุผล เช่น ลดลง 15% |
| ทำการตรวจสอบ, ได้มีการตรวจสอบ | ตรวจสอบ |
| มีความสำคัญเป็นอย่างมาก | สำคัญ (หรือบอกว่าสำคัญอย่างไร) |
| ในส่วนของการวิเคราะห์ | การวิเคราะห์... / ด้านการวิเคราะห์ |
| เพราะว่า... ก็เลย... | เนื่องจาก... จึง... |
| ถ้า | หาก / ถ้า (ใช้ได้ทั้งคู่ แต่สม่ำเสมอ) |
| อันนี้, ตัวนี้ | ค่าดังกล่าว, อุปกรณ์นี้ |

## คำ AI ที่พบบ่อยในรายงาน (grep ก่อนส่ง)

นอกจากรายการใน `thai-prose/forbidden-phrases.md` ให้ตรวจคำเหล่านี้ ทุกคำมีที่ใช้ที่ถูกได้ แต่ถ้าพบบ่อย แปลว่ามีกลิ่น AI:

- `ในยุคปัจจุบัน` / `ในโลกที่เปลี่ยนแปลงอย่างรวดเร็ว` — เปิดเรื่องแบบกว้างเกินไป ให้เปิดด้วยปัญหาจริงของงาน
- `มีบทบาทสำคัญ` / `เป็นหัวใจสำคัญ` / `เป็นกุญแจสำคัญ`
- `อย่างมีประสิทธิภาพและประสิทธิผล` — ระบุว่าดีขึ้นอย่างไร
- `ทั้งนี้` / `อนึ่ง` ต้นย่อหน้าซ้ำ ๆ (ใช้ได้ในรายงานแบบ C ไม่เกินหนึ่งครั้งต่อหัวข้อ)
- `ซึ่ง` ต่อกันหลายชั้นในประโยคเดียว
- `ยิ่งไปกว่านั้น` / `นอกจากนี้ยัง...อีกด้วย` ทุกย่อหน้า
- `ถือเป็น...ที่น่าสนใจ` / `ถือได้ว่า...`
- `เพื่อให้เกิดประโยชน์สูงสุด` — ไม่มีข้อมูล ระบุประโยชน์จริง
- `ไม่เพียงแต่...แต่ยัง...` ในทุกส่วน
- ปิดทุกบทด้วย `กล่าวโดยสรุป` / `โดยสรุปแล้ว` แล้วซ้ำเนื้อหา

## การเขียนผลและการอภิปราย

- บอกผลก่อน แล้วค่อยบอกว่าผลหมายความว่าอะไร: `SPC ของ CLOX2 สูงกว่า CLOX1 เฉลี่ย 8% ในช่วงโหลดต่ำ แสดงว่า...`
- แยกข้อเท็จจริงที่วัดได้ออกจากข้อสันนิษฐาน ใช้ `คาดว่า / น่าจะ / อาจ` เฉพาะส่วนที่เป็นข้อสันนิษฐานจริง
- ระบุข้อจำกัดของข้อมูลตรง ๆ (ช่วงเวลาสั้น ข้อมูลขาดหาย เครื่องมือวัดคลาดเคลื่อน)
